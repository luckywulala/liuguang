# 流光 · 小说推荐与排行榜

一个纯静态的小说推荐站，苹果 **Liquid Glass（液态玻璃）** 风格，**水墨配色**。
不用框架、不用构建、零依赖，三个文件丢进任何静态托管就能跑。

## 配色

- 底：宣纸色 `#f7f4eb`，背景是几团淡墨慢慢晕开 + 纸纤维噪点
- 字：墨色 `#23282e`，标题用宋体
- 点缀：青墨 `#45647f`（数据）、朱砂 `#b0402f`（前三名、评分、命中高亮、标题前的短竖）

想换配色只改 `styles.css` 开头那组 CSS 变量即可，别处都不是硬编码。

## 打开方式

直接双击 `index.html` 就能看（`file://` 打开也可以，不需要服务器）。

想在手机上试，在项目目录起个本地服务：

```bash
python3 -m http.server 8899
# 然后浏览器打开 http://127.0.0.1:8899/
```

## 功能

- **排行榜**：62 本书，可按 热度 / 评分 / 收藏 / 新近 四种维度排序，前三名是朱砂色
- **推荐**：每日书单大卡（可点右上角换一本）+ 12 本"你可能也会喜欢"
- **分类**：科幻、悬疑、玄幻、都市、历史、文学、武侠、言情、轻小说，chips 横向滑动
- **搜索**：书名、作者、分类、标签、金句全文匹配，命中词高亮；输入即搜，回车跳到分类页看全部结果
- **详情**：底部抽屉（桌面上是居中弹窗），显示评分/热度/收藏/字数、金句、简介、标签
- **收藏**：卡片心形或详情页按钮，存在 localStorage，刷新不丢

快捷键：`/` 聚焦搜索，`Esc` 关弹窗或清空搜索。

## 液态玻璃是怎么做的

参考了 [shuding/liquid-glass](https://github.com/shuding/liquid-glass)（SVG 位移贴图折射）
和 [rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react) 的思路，但没引入它们的代码，
自己用四层叠加实现，手机上也能跑得动：

1. `backdrop-filter: blur() saturate() brightness()` —— 玻璃的"透"，直接折背景（浅色玻璃低饱和，不然会发糊）
2. 多层 `inset box-shadow` —— 上下左右的白色高光，玻璃的"厚"
3. `conic-gradient` + `mask-composite: exclude` —— 边缘一圈彩色折射亮线
4. SVG `feTurbulence` + `feDisplacementMap` —— 作用在边缘折射层和 hero 的墨雾上，产生轻微流动畸变

背景是 4 团 `blur(66px)` 的淡墨缓慢晕开（30s 一循环，multiply 混合），玻璃后面的东西一直在动，
透过去的光就有"活的"感觉，这是液体的关键。

性能上：`backdrop-filter` 只用在顶栏、标签栏、卡片、抽屉这些区块上，列表行用的是半透明渐变 +
一层轻模糊，避免几十个元素同时做实时模糊。

尊重 `prefers-reduced-motion`：开了减少动效就关掉光斑和过渡。
